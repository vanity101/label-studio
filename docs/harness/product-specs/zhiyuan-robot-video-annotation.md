# 智源机器人视频时间轴标注

## 能力

在 **同一条视频、同一条时间轴、同一套区间标签** 上标注机器人操作阶段。细致度：同一任务要求越细，同一轴上的标签数量越多、描述越细。

倒水示例（手册原文）：

- 简单：抓住水瓶-倒水-放在桌上
- 中等：抓住水瓶-将水瓶抬起-倒水-放在桌上
- 复杂：带「用右手」等主语，步骤更多

预置阶段标签字面量：`Static`、`grasp`、`Place`、`End`。

- `Static` 可出现在视频开头（未触动之前）和结尾（收回不动之后到最后一帧）。
- 下一标签开始帧默认 = 上一标签结束帧 + 1。
- 默认各标签不重叠；特殊任务才允许重叠。不允许时用英文描述把两动作用 `and` 连成一条。产品不硬互斥、不自动裁剪。

整段可另记：本任务细致度（简单 / 中等 / 复杂）、动作序列文本、异常标记（废弃 / 异常 / `abnormal`）。这些不是第二、第三条时间轴。

单视角用一个 `Video` + 一条 `TimelineLabels`。2–3 视角用多个 `Video`，主视角挂时间轴，侧视角可隐藏时间轴；镜头字段名以数据包为准。

## 非目标（跨轮仍成立，除非另开计划）

- 自动质检引擎、帧边界对错判定、强制互斥
- 账号 / 权限 / 领取任务工作流的系统强制（手册已有，属后续）
- 重写 Label Studio 核心、自研播放器、完整 clone
- ML Backend 预标注
- 把手册截图 / 培训视频做成产品功能



## 复用

手册已有单视角 / 多视角 Labeling Config 骨架；Label Studio `Video` / `TimelineLabels` / 整段 `Choices` / `TextArea`；Project / Task / Annotation / Export；官方 `ranges` + `timelinelabels`；官方 Docker 镜像与仓库 `docker-compose.yml`。视频建议 MP4 + H.264 + 恒定帧率。

## 验收要点

配置可当 Labeling Config 使用；预置字面量含 `Static` / `grasp` / `Place` / `End`；同一任务可标多段且头尾都可以是 Static；导出能还原每段 start / end 与标签名；细致度不是三套时间轴；不改 `label_studio/` / `web/` 内核。
