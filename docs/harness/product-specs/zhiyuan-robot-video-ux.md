# 智源机器人视频标注：前端交互

本摘要叠加在 `zhiyuan-robot-video-annotation.md` 之上，**不取代**上一轮 overlay 能力（同一条时间轴、阶段字面量、官方导出形状、初步能跑模板）。

## 能力

在官方 Label Studio 上做浅克隆前端改造（`web/` 或仅编辑器相关路径）并自建镜像，使标注交互接近手册与智源生产界面。不重写整个栈。

已确认：

1. **范围**：改前端，不是只改 XML；允许浅克隆 `web/`、自建 Docker 镜像。**只做简单单视角。**
2. **点标签切段**：上一标签结束帧 + 1 → 当前播放头；第一段为第 1 帧 → 播放头。点了即出现在 Regions，不必再在轴上画。
3. **侧栏**：选中 Region 可改起止帧和名称（标签名下拉切换阶段字面量）。
4. **排序默认**：按点击 / 创建顺序，先点的在上；不是按视频开始帧。不交付把名单上下拖来改顺序。
5. **废弃**：与阶段标签同一条顶部栏，只要这一个字面量。点击 = 视频有问题，停止对本视频的标注（不能再标阶段，也不再改已有区间）；已有区间保留可见；不占时间轴区间。
6. **重叠**：允许。播放头早于上一结束帧时点新标签不拒绝；新段为播放头与上一结束帧之间的闭区间。

导出：时间轴仍是 `ranges` + `timelinelabels`；整视频「废弃」与区间结果可区分。

## 非目标

- 完整 clone、重写 Label Studio、自研播放器
- 把废弃做成一段时间轴 `ranges`
- 「异常」「abnormal」作为本轮废弃交互
- Manual 拖拽改 Regions 列表顺序
- 三套时间轴
- Django 大规模改造（仅当不改就无法保存时再单独立项）
- 多视角（本轮只做简单单视角，不改多视角模板、不验收三路视频）
- 覆盖上一轮 overlay 规格

## 复用

官方 Video + TimelineLabels；现有 overlay 单视角模板；Docker / Colima 官方镜像；手册标注端操作；智源生产界面 Selection Details 改名 + 改帧。

## 验收要点

第 N 帧点第一标签 → start=1、end=N；再 M>N 点第二标签 → start=N+1、end=M；选中 Region 能改名和 start/end；Regions 先点的在上；顶部仅「废弃」，点后停止标注（不能再标阶段、不能再改已有区间，仍可提交）；允许重叠；不重写整个 Label Studio。
